# SMS Forwarder

一个面向 Android 的轻量级消息转发工具，用于将**短信**与**未接来电**统一接入同一条转发链，并实时发送到你配置好的通知渠道。

## 核心特性

- 轻量极简
- 省电
- 长期后台运行
- 稳定转发
- 低资源占用

个人刚好需要，所以写这个项目，非常适合作为备用机上的长期运行。

---

## 使用场景

适用于以下场景：

- 将备用机短信实时转发到主力设备
- 使用飞书 / 钉钉接收验证码通知
- 用邮箱异地归档短信与来电记录
- 在旧 Android 设备上部署轻量消息转发节点
- 长期运行的个人通知中继工具

---

## 项目简介

SMS Forwarder 会监听两类事件：

- 短信（SMS）
- 未接来电（Missed Call）

随后将它们统一转换为内部标准载荷（`ForwardPayload`），再交由统一转发链进行分发。

**这意味着：**

- 短信与未接来电共用同一套转发流程
- 共用同一套日志系统
- 共用同一套统计系统
- 共用同一套去重逻辑
- 共用同一套失败记录与队列机制

---

## 功能特性

### 统一事件转发链

- 统一处理短信与未接来电
- 统一 `ForwardPayload` 数据结构
- 统一队列与分发逻辑
- 内置事件去重机制

### 多渠道转发

支持同时启用多个转发渠道：

- **DingTalk Webhook**
- **Feishu Webhook**
- **SMTP Email**

每条事件会广播到所有**已启用且配置完整**的渠道。

### 渠道能力

**DingTalk**
- 支持可选 secret 加签

**Email**
- 支持 SMTP
- 支持 TLS
- 支持 STARTTLS

### 后台运行与稳定性

项目针对 Android 长期后台运行做了优化：

- 前台服务常驻
- 开机自动恢复
- 应用更新后自动恢复
- 减少重复唤醒
- 减少重复通知刷新
- 减少重复持久化操作

**针对 Xiaomi / MIUI / HyperOS：**

- 支持快速跳转自启动设置
- 支持快速跳转电池优化设置
- 支持快速跳转应用详情页

### 数据记录与统计

内置基础统计与记录功能：

- 累计接收数量
- 累计转发成功数量
- 累计转发失败数量
- 最近转发记录
- 最近失败原因

## 工作流程

```
SMS / Missed Call Notification
         ↓
Normalize to ForwardPayload
         ↓
      Dedupe
         ↓
ForwarderService Queue
         ↓
  ChannelDispatcher
         ↓
DingTalk / Feishu / Email
         ↓
 Logs / Stats / Failures
```

## 权限说明

应用依赖以下权限或系统授权：

| 权限 / 授权 | 用途 |
|------------|------|
| `RECEIVE_SMS` | 接收短信广播 |
| 通知读取授权 | 识别未接来电通知 |
| `POST_NOTIFICATIONS` | 展示前台服务通知 |

## 快速开始

### 1. 安装 APK

将 APK 安装到 Android 设备。

### 2. 开启后台守护

首次启动后开启：

- 后台守护
- 前台服务

### 3. 授予权限

授予：

- 短信权限
- 通知读取权限
- 系统通知权限

### 4. 配置转发渠道

至少配置一个可用渠道：

- 钉钉
- 飞书
- 邮件

### 5. 建议关闭电池优化

为了获得更好的后台稳定性，建议：

- 关闭电池优化
- 开启自启动
- 最近任务锁定应用（MIUI / HyperOS 推荐）

---

## 注意事项

- 只有”已启用且配置完整”的渠道会参与发送
- 如果没有任何可用渠道，事件仍会进入统计系统
- 未接来电识别依赖系统通知结构
- 不同 Android 厂商的兼容性可能存在差异

**推荐额外开启：**

1. 自启动
2. 无限电量模式
3. 最近任务锁定
4. 允许后台无限制运行
